# Extvedio

إضافة Chrome لتحسين مشاهدة الفيديوهات: تعرض مدة الفيديو ووقته الحالي، وتفتح الفيديو
بملء الشاشة مع الحفاظ على أبعاده كاملة، وتحمّل ترجمة عربية من ملف محلي باتجاه RTL.

## التثبيت

1. افتح `chrome://extensions` في Chrome.
2. فعّل **وضع المطوّر**.
3. اختر **تحميل إضافة غير مضغوطة** وحدد مجلد المشروع.
4. افتح صفحة تحتوي على فيديو، ثم اضغط أيقونة الإضافة.

## الاستخدام

- يعرض مربع الإضافة الوقت الحالي والمدة الكلية.
- اختر **ملء الشاشة** لعرض إطار الفيديو كاملاً دون قص.
- اختر ملف ترجمة عربي بصيغة `.srt` أو `.vtt` لتشغيله باتجاه الكتابة من اليمين إلى اليسار.

تحتاج الترجمة إلى ملف ترجمة جاهز؛ الإضافة لا تنشئ ترجمة تلقائية من صوت الفيديو.
تعمل مع عناصر HTML video المتاحة في الصفحة، وقد لا تتوافق مع مشغلات تعتمد تقنيات
خاصة أو تمنع إضافة مسارات ترجمة خارجية.
